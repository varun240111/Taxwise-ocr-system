# TaxWise Vault

AI-powered Indian tax planning platform.

## Features

- OTP Authentication
- Salary Slip Upload
- OCR Extraction
- AWS S3 Storage
- Tax Calculation
- Active Salary Management
- Tax Planning Dashboard

## Tech Stack

Frontend:
- React
- TailwindCSS
- Redux Toolkit
- Axios

Backend:
- Node.js
- Express.js
- MongoDB
- JWT Auth
- AWS S3

OCR:
- Tesseract.js
